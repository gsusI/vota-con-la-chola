# publicdata_policy_es

Reusable Spanish public-policy processing helpers.

Current scope:
- map BOE, Moncloa, PLACSP and BDNS source records into `policy_events`
- map DIR3 source records into government organisation units and relationships
- harmonize indicator-series source records into `indicator_series` and `indicator_points`

Vota still owns CLI orchestration, product copy, static snapshots, Explorer UI and citizen-facing packaging.
