# Convocatoria preparada — no enviada

Publicamos una alfa de Vota Con La Chola para seguir una adjudicación hasta su expediente: 120 resultados PLACSP de un corte histórico parcial, con CSV/Parquet, XML capturado y tres consultas que puedes reproducir con Python.

Buscamos una primera aportación concreta: descargar el paquete en un entorno nuevo, ejecutar la consulta por proveedor y contar si el resultado coincide o dónde se atasca la guía. No necesitas conocer contratación pública ni tener acceso privado.

Demo: https://votaconlachola.org/spending/
Guía: https://github.com/gsusI/vota-con-la-chola/blob/main/docs/examples/placsp-launch/README.md
Tareas: https://github.com/gsusI/vota-con-la-chola/blob/main/docs/community/placsp-launch-tasks.md

Es una alfa técnica: datos históricos, cobertura parcial y revisión comunitaria pendiente. Adjudicado no significa pagado.
