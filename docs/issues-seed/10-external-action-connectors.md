# Seed 10: external action connectors

## Titulo sugerido

Abrir la primera ola de conectores fuera del parlamento para gasto, acuerdos, geopolitica e indicadores

## Por que importa

El framework completo no puede descansar solo en votos parlamentarios. Necesita al menos una muestra reproducible de accion ejecutiva, dinero publico, acuerdos/influencia, geopolitica u outcomes.

## Alcance

- priorizar una primera fuente oficial por cada eje que sea viable
- documentar limites de cobertura y trazabilidad
- publicar una muestra navegable con evidencia y notas de calidad

## Definition of Done

- existe al menos un nuevo conector fuera del parlamento con salida publicada
- el conector deja clara su relacion con `policy_events` o el modelo equivalente
- se documentan blockers cuando la fuente no sea reproducible
- el tracker refleja el nuevo slice sin falsos `DONE`
