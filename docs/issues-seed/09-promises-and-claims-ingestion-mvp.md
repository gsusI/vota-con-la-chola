# Seed 09: promises and claims ingestion MVP

## Titulo sugerido

Implementar el MVP de ingesta de promesas y claims con evidencia textual

## Por que importa

El proyecto solo puede comparar "dicen vs hacen" si la capa de declaraciones/promesas tiene reglas claras, evidencia textual y estados de ambiguedad.

## Alcance

- definir el modelo minimo de claims/promesas
- ingestar una primera fuente de textos programaticos o declarativos
- extraer postura, actor, tema y evidencia textual con confianza base

## Definition of Done

- existe especificacion o doc operativa del modelo de claims/promesas
- al menos una fuente real queda ingerida de forma reproducible
- cada claim publicado tiene evidencia textual y metadatos de confianza
- los estados ambiguos o no comparables quedan explicitados
